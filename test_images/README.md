# Test images

Put your own leaf photos here (`.jpg`, `.jpeg`, `.png` or `.webp`) to test the model.

- One leaf, filling most of the frame, in daylight works best.
- Optional: start the file name with the true disease, e.g. `Tomato late blight - my farm.jpg`, and the app will mark the prediction right or wrong.

Open the app, go to **Diagnose a leaf**, choose **My test photos**, then pick a photo or press **Test all photos**.
